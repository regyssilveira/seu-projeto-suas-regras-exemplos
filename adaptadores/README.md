# Adaptadores de ambiente

Consulta documental em 04/10/2026; não é certificação de compatibilidade.

Copie a pasta completa de uma receita para um destino de projeto documentado:
- Codex local: .agents/skills/nome; fonte https://learn.chatgpt.com/docs/build-skills
- Claude Code: .claude/skills/nome; fonte https://code.claude.com/docs/en/skills
- Gemini CLI: .gemini/skills/nome; fonte https://geminicli.com/docs/cli/skills/
- GitHub Copilot: .github/skills/nome; fonte https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills

Existem outros destinos conforme produto; confira a documentação da superfície e versão usadas. A biblioteca receitas não é um destino de descoberta automático. Antes de marcar compatibilidade, verifique reconhecimento, ativação, tarefa e evidência em cada ambiente.

## Núcleo independente
Use contratos/chamados.md e modelos/perfil-do-projeto.md. Fornecer o procedimento como texto é uma alternativa manual; não equivale a instalar uma skill.

## Delphi
Aplique o contrato no seu projeto. Registre versão, plataforma, configuração, projeto e preparação do compilador. Nenhuma compilação Delphi foi realizada neste material. Não há promessa de que uma ferramenta remota tenha acesso ao seu ambiente local.
