# LAB-03 — Guia Markdown

## Estado inicial
modelos/perfil-do-projeto.md. Caminhos referem-se à raiz do repositório, salvo o prefixo estados do LAB-01, que fica em laboratorios. Use a tag rascunho-v1 em cópia de exercício. Preserve suas alterações antes de iniciar.

## Procedimento
Crie docs/guia-do-projeto.md com descrição, caminhos, preparação e verificação. Use links relativos e separe comando de resultado esperado.

## Critérios
Cada caminho existe e cada comando executável foi tentado no diretório indicado.

## Comentário da solução
Guia que aponta ao contrato e registra o comando node --test testes/*.test.cjs para a referência, sem impor Node a outros projetos.

## Registro e limites
Procedimento documental; guia depende do projeto escolhido.
Preencha modelos/registro-de-execucao.md com ambiente, pedido, comandos, saída e limitações. Não trate resultado esperado como observado. Para casos de lógica da referência: node --test testes/*.test.cjs, na raiz. Para tarefas documentais ou de agente, esse comando não substitui o ensaio descrito.
